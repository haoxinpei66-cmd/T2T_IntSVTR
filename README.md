# T2T_IntSVTR
This repository contains the primary analysis scripts for the comparative evaluation of variant datasets from second- and third-generation sequencing technologies.

## scripts
以下是script目录下的脚本说明

| script | Description |
|-----------|-------------|
| 01.py | Script for comparing INV variants in second- and third-generation datasets |
| 02.py | Script for comparing TR variants in second- and third-generation datasets |
| 03.py | Script for comparing SV variants in second- and third-generation datasets |
| 04.py | Scripts for calculating the total count of various types of SVs and for performing concordance analysis. |
| 05.py | Script for analyzing the consistency of various SVs across different genomic regions |
| 06.py | Scripts for precision analysis of various SVs |
| 07.py | Scripts for analyzing the precision of various types of SVs across different length ranges |
| 08.py | Scripts for analyzing the precision of various types of SVs across different genomic regions |
| 09.py | Scripts for recall analysis of various SVs |
| 10.py | Scripts for analyzing the recall of various types of SVs across different length ranges |
| 11.py | Scripts for analyzing the recall of various types of SVs across different genomic regions |
| 12.py | Scripts for analyzing the consistency of TRs associated with various reflens across different genomic regions |
| 13.py | Scripts for analyzing the consistency of TRs associated with various motifs across different genomic regions |
| 14.py | Scripts for analyzing the recall of various motifs within TRs across different genomic regions |
| 15.py | Scripts for analyzing the recall of various reflens within TRs across different genomic regions |
| 16.py | Scripts for analyzing the precision of various reflens within TRs across different genomic regions |
| 17.py | Scripts for analyzing the precision of various motifs within TRs across different genomic regions |
